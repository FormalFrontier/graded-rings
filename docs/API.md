## Scope distinctions

The full localized ring and its degree-zero subring are different objects.
The degree-multiplying map is distinct from this same-ring localization grading;
`d = 0` still requires an explicit degree-compatibility witness, and the chart
element need not be homogeneous for the restriction square. It does not construct
a Proj or scheme map.
The polynomial results do not identify a general graded ring with a polynomial
ring, and the valuation results do not apply to arbitrary rings with zero divisors.
The positive-Veronese result is algebraic generation, not a coefficient-
regrouping theorem or a chart/scheme equivalence. Coherent high tails induce
equivalent selected rings without extending the equivalence to missing low
degrees or asserting a geometric equivalence. No claim about complete
coverage of a mathematical book follows from this API.

## Polynomial modules and Rees evaluation kernels

All three interfaces use exactly `[CommRing R] [AddCommGroup M] [Module R M]`,
with independent ring and module universes. Their ordinary direct imports are
`GradedRings.PolynomialModule.Monic`,
`GradedRings.PolynomialModule.EvaluationKernel`, and
`GradedRings.ReesModule.EvaluationKernel`. The aggregate `GradedRings` publicly
imports each leaf, so both generic interfaces are available independently of
the natural Rees presentation. The generic leaves use only Mathlib APIs and do
not depend on a Rees construction.

### Generic coefficient preimages and ambient factors

For `P : ℕ → Submodule R M` with `Antitone P`, a polynomial `g` with
`g.Monic`, and `q : PolynomialModule R M`,
`PolynomialModule.monic_smul_coeff_mem_iff` states

```text
(∀ n, (g • q).coeff n ∈ P n) ↔ ∀ n, q.coeff n ∈ P (n + g.natDegree).
```

No ideal or ideal-compatibility condition on `P` is needed. The shift uses the
actual `g.natDegree`, including for monic constants and zero coefficient rings.
The constant-bottom specialization gives `monic_smul_injective` on the arbitrary
polynomial module, without regularity of any coefficient or freeness of `M`.
For `M = R`, the existing scalar law of `equivPolynomialSelf` sends `g • q` to
`g * equivPolynomialSelf q`, agreeing with scalar monic multiplication.

`PolynomialModule.eval_eq_zero_iff_exists_smul_X_sub_C` states, for every
`r : R` and `p : PolynomialModule R M`,

```text
eval r p = 0 ↔ ∃ q, (Polynomial.X - Polynomial.C r) • q = p.
```

The factor lies in the existing polynomial module; no module-valued division
operation or chosen quotient is defined. For `p : PolynomialModule R R`,
`exists_smul_X_sub_C_eq_iff_dvd` identifies this same existence statement with
`(Polynomial.X - Polynomial.C r) ∣ equivPolynomialSelf p`. This is agreement
with the stock scalar factor theorem through the existing equivalence, not a
new scalar polynomial division theory.

### The canonical successor-tail map

Let `I : Ideal R` be arbitrary and `H : I.Filtration M` be a natural filtration.
For this explanation write

```text
B = reesAlgebra I
E = H.submodule
S = (H.toIntFiltration.natTail (1 : ℤ)).submodule.
```

These abbreviate existing objects, not new definitions. The stage in polynomial
degree `n` of the source filtration is `H.N (n + 1)`. In particular, a source
constant coefficient belongs to `H.N 1`, not just `H.N 0`.

The definition `Ideal.Filtration.mulXSubC` has type

```text
H.mulXSubC r : S →ₗ[B] E.
```

Its value uses the existing tail-one-to-tail-zero transition and coefficientwise
identity `reesMap`s into `H.submodule`. More precisely, if `i0` and `i1` denote
these identity coefficient maps from tails zero and one, the defining expression
is `i0.comp (H.toIntFiltration.natTailTransition 0 1 h01) -
(algebraMap R B r) • i1`. Here `h01` is just the integer inequality `0 ≤ 1`.
This reuses the canonical natural-to-integer extension and cutoff transition;
it introduces no successor-filtration wrapper, shift map or new scalar action.

The nine accompanying laws are in `Ideal.Filtration`:

| Declaration | Mathematical content |
| --- | --- |
| `coe_mulXSubC` | The underlying polynomial-module value is `(Polynomial.X - Polynomial.C r) • p`. |
| `coeff_mulXSubC_zero` | The degree-zero coefficient is `-(r • p.coeff 0)`. |
| `coeff_mulXSubC_succ` | The degree-`n + 1` coefficient is `p.coeff n - r • p.coeff (n + 1)`. |
| `coe_mulXSubC_single` | For `m ∈ H.N (n + 1)`, the admissible source `single R n m` maps, on underlying polynomials, to `single R (n + 1) m - single R n (r • m)`. |
| `coe_mulXSubC_zero_transition` | At `r = 0`, the underlying polynomial value is the existing cutoff transition from tail one to tail zero. |
| `mulXSubC_injective` | `H.mulXSubC r` is injective for every `r : R`. |
| `range_mulXSubC` | `LinearMap.range (H.mulXSubC r) = LinearMap.ker (H.evalRees r)` as submodules over `B`. |
| `evalRees_eq_zero_iff_existsUnique_mulXSubC` | For `p : E`, `H.evalRees r p = 0` exactly when there is a unique `q : S` with `H.mulXSubC r q = p`. |
| `mulXSubC_naturality` | Every original-`R`-linear map preserving all natural stages commutes with `mulXSubC r` through the existing coefficientwise Rees maps on the successor tails and original Rees modules. |

In the coefficient formulas, `p.coeff` means the coefficients of the underlying
polynomial-module element. For naturality, the target module `N` has its own
independent universe. Given `K : I.Filtration N` and `f : M →ₗ[R] N`, the sole
compatibility condition is `∀ n, H.N n ≤ (K.N n).comap f`; neither strict stage
images nor ambient injectivity or surjectivity is required.

Evaluation is still the existing map

```text
H.evalRees r : E →ₛₗ[(Polynomial.evalRingHom r).comp
  (reesAlgebra I).val.toRingHom] H.N 0.
```

Its kernel is a `B`-submodule because `B` is the source scalar ring of this
semilinear map. There is no new `B` action on the original, possibly proper
`H.N 0`; the constant-single section remains only original-`R`-linear. Thus the
range/kernel identity does not assert a `B`-linear short exact sequence ending
in `H.N 0`. The multiplier is an **ambient** polynomial: `X - C r` need not
belong to `B`, and multiplication need not define a self-map of `E`. The source
successor-tail condition is essential. No equality with a positive-ideal
multiple or quotient equivalence is asserted.

All scalars `r`, all ideals and zero rings are allowed. The zero-ring case is
handled internally, without a `[Nontrivial R]` premise. No regularity assumption,
finite generation of the ideal, stages or ambient module, stability,
separatedness, exhaustivity, completeness, Noetherianity, flatness or
normalization `H.N 0 = ⊤` is assumed.

## Intrinsic finiteness of integer associated gradeds

Let `R` be a commutative ring, `I : Ideal R`, and `M` an additive commutative group
with its original `R`-module structure. For any `F : I.IntFiltration M`, put
`C = reesAlgebra I ⧸ I.map (algebraMap R (reesAlgebra I))`. The full direct sum
`F.AssociatedGraded` uses its existing `Ideal.IntFiltration.moduleReesQuotient`
action, not just residue-coefficient scalars or a natural tail.

Under `[IsPrecomplete I R]`, `hI : I.FG`, separation
`hsep : (⨅ n : ℤ, F.N n) = ⊥` and exhaustivity
`hexhaustive : (⨆ n : ℤ, F.N n) = ⊤`, the theorem
`F.finite_associatedGraded_iff_finite_fg_stable hI hsep hexhaustive` states

```text
Module.Finite C F.AssociatedGraded ↔
  Module.Finite R M ∧
    (∀ n : ℤ, (F.N n).FG) ∧
    (∃ c : ℤ, ∀ n : ℤ, c ≤ n → I • F.N n = F.N (n + 1))
```

Use `.mp` to obtain the three original-module conclusions from finite associated
graded, and `.mpr` to prove that finiteness from the conjunction. There is no
finite-associated-graded instance in the hypotheses. All stages, including negative
ones, are the original `R`-submodules; the ring and module universes are independent.
No Noetherianity, coefficient Hausdorffness, ambient-module precompleteness,
normalization at zero or chosen top stage is needed.

The forward implication combines the weighted-generation finiteness consequences.
The reverse implication uses `finite_of_stable_ge_of_fg_le`, which only needs
ambient finiteness, exhaustivity, stability from `c`, and FG of stages at or below
`c`. Without exhaustivity or ideal FG, the separate natural-tail criterion still
applies under precompleteness and separation, but its projection-surjectivity
condition cannot be dropped.

## Degree-multiplying localization maps

The degree-multiplying map module does **not** replace the existing same-ring grading or
zero-component equivalence. For natural gradings `𝒜`, `ℬ` of arbitrary
commutative rings, its ordinary unital `f : A →+* B` must satisfy
`hdeg : ∀ n a, a ∈ 𝒜 n → f a ∈ ℬ (d * n)` and the arbitrary submonoids must
satisfy `hPQ : P ≤ Q.comap f`. This includes `d = 0` only when `hdeg` is
provided; no domain, regular-denominator or positive-scaling assumption is
added. The source chart element need not be homogeneous for
`Away.mapDegreeMul_awayMap`; only the multiplicative restriction factor does.

## Homogeneous lifts

The generic graded-semiring theorem `GradedRingHom.surjective_gradedAddHom`
derives surjectivity on **each whole component** from surjectivity of the
ambient graded map, not from an assumed homogeneous preimage. The three
`MvPolynomial` declarations evaluate with the actual degree-zero ring `𝒮 0`
as coefficients and **all** degree-one elements `𝒮 1` as variables in an
arbitrary nonnegative graded `CommRing S`. `exists_isHomogeneous_aeval` returns
a degree-`m` homogeneous polynomial evaluating to `s ∈ 𝒮 m`, including `m=0`,
provided exactly `Algebra.adjoin (𝒮 0) (𝒮 1 : Set S) = ⊤`. It does not
assume a finite set of generators, a domain, a reduced ring, a nontrivial
ring, a field, or by itself a conclusion about positive Veronese degree-one generation.
The [standalone guide](HomogeneousLifts.md) includes a direct free-polynomial
client that **proves** this algebra-generation premise rather than assuming it.

The lift alone does not establish positive-Veronese generation or source coverage.

## Weighted polynomial evaluation

For an arbitrary natural grading `𝒮` of a `CommRing S`, variable type `ι`,
weights `w : ι → ℕ` (including zero), and `x : ∀ i : ι, 𝒮 (w i)`, all four
declarations use exactly `𝒮 0` as the coefficient ring. With no finiteness,
generation, positivity, domain, field or nontriviality hypotheses,
`MvPolynomial.IsWeightedHomogeneous.aeval_mem` preserves weighted degree;

## Positive-weight exponent blocks

`Finsupp.weightedBlockSize w` requires only a finite index type and defines

## Whole-Veronese residue projections

For a naturally graded commutative ring and `0 < n`, `r < n`, the additive
`residueProjectionAdd 𝒮 n r` filters the old homogeneous decomposition by
degree remainder. `residueProjection 𝒮 n r hn hr` is linear over the **whole

`(inclusion 𝒮 n).toAlgebra`, not a scalar action on individual old fibers.
`residueProjection_of_mem` decides the image of a homogeneous element and

finiteness of this linear image from ambient `Module.Finite`, while
`residueProjection_range_finite_of_finiteType` uses
`[Algebra.FiniteType (𝒮 0) S]` and `inclusion_finite` to obtain the same conclusion. The
[standalone guide](VeroneseResidue.md) maps all supporting additive,
componentwise and scalar-compatibility declarations. Its [direct ordinary
client](../test/VeroneseResidue.lean) and [aggregate-root
witness](../test/RootClient.lean) check usable public interfaces.
This projection module alone does not supply a shifted
external-sum equivalence; the [sibling module](VeroneseResidueModule.md) does
under positive reduced-index hypotheses. Neither supplies an `n = 0` bijection.

## Proof ideas

A homogeneous quotient decomposes by projecting the original components:
homogeneity makes the decomposition vanish on the ideal, so it descends.
For localization, project a numerator into the degree shifted by its denominator;
the localization relation makes the result independent of representatives, even
when denominators are zero divisors.

Finite generation of the irrelevant ideal yields positive-degree homogeneous
generators. Strong induction on degree turns ideal generation into algebra
generation over degree zero. The Noetherian criterion then combines this with
the degree-zero Noetherian and finite-type results in mathlib.

For integer-graded prime correspondence, powers of a positive-degree homogeneous
unit move suitable powers of homogeneous elements to degree zero. This explains
why radical extension, rather than unmodified extension, is the inverse.

The symmetric algebra's universal property sends degree-one generators into
their direct sum, giving the basis-free grading and its functorial maps.
In a homogeneous polynomial localization, total degree bounds prime multiplicity;
order zero forces the remaining numerator to be a nonzero scalar, hence a unit.
Additivity of denominator order then makes an order-one element irreducible.
