# A polynomial control for a regular principal ideal

## Objects and scope

For an ideal `I` of a commutative ring `R`, retain the original objects

- `B = reesAlgebra I ⊆ R[t]`;
- `A = R ⧸ I`;
- `J = I.map (algebraMap R B)` and `C = B ⧸ J`, with its existing `A`-algebra structure and `R`-algebra tower.

Write `q : B → C` for the quotient ring homomorphism and `π : R → A` for the coefficient
quotient. Constants belong to `B`. For `a ∈ I`, the polynomial `a t` also belongs to
`B`, so it determines `η = q(a t) ∈ C`. The forward map considered here is precisely

`F = Polynomial.aeval η : A[T] →ₐ[A] C`.

It uses the existing scalar map `A → C` and sends `T` to `η`. No `A`-algebra structure
on `B` is introduced, and `q` is not being regarded as an `A`-algebra homomorphism.

The positive result below is restricted to `R = ℤ`, `I = (2)`, and `a = 2`. The unit and
trivial-ring boundaries are treated separately. These cases do not prove a general
regular-principal comparison or describe the full kernel of a symmetric-algebra map.

## The integral example: unique normalized coefficients

Set `R = ℤ`, `I = (2)`, and keep `A = ℤ ⧸ (2)`. In particular, `A` is nontrivial; it can
be identified with `𝔽₂`, but no change of coefficient ring is needed. Membership in the
original Rees algebra is the coefficient condition

`P ∈ B  ⇔  coeffₙ(P) ∈ 2ⁿℤ` for every `n ≥ 0`.

Consequently every `P ∈ B` has integers `cₙ(P)` satisfying

`coeffₙ(P) = 2ⁿ cₙ(P)`.

Each integer is unique because `2ⁿ ≠ 0` in `ℤ`, so multiplication by `2ⁿ` is injective.
The sequence has finite support: wherever the coefficient of `P` vanishes, the same
cancellation gives `cₙ(P) = 0`. Thus there is an equality in `B`, not merely in its
quotient,

`P = ∑ₙ cₙ(P) (2t)ⁿ`,

where integers in the sum act as constant elements of `B`.

Define a polynomial with coefficients in the original quotient ring by

`D(P) = ∑ₙ π(cₙ(P)) Tⁿ ∈ A[T]`.

Normalization is compatible with addition and multiplication. For addition, uniqueness
gives `cₙ(P + Q) = cₙ(P) + cₙ(Q)`. For multiplication, writing `cᵢ = cᵢ(P)` and `dⱼ =
cⱼ(Q)`, the usual coefficient formula gives

`coeffₙ(PQ) = ∑ᵢ₊ⱼ₌ₙ (2ⁱ cᵢ)(2ʲ dⱼ) = 2ⁿ ∑ᵢ₊ⱼ₌ₙ cᵢ dⱼ`.

Uniqueness of normalized coefficients therefore gives

`cₙ(PQ) = ∑ᵢ₊ⱼ₌ₙ cᵢ dⱼ`.

Together with the normalized coefficients of `0` and `1`, these identities prove that
`D` is a ring homomorphism. If `ι_B : ℤ → B` is the original constant map and `κ : A →
A[T]` is the polynomial constant map, then

`D(ι_B(m)) = κ(π(m))` for every `m ∈ ℤ`.

Thus `D` also respects the `ℤ`-algebra structures, where `A[T]` receives its `ℤ`-algebra
structure through `ℤ → A → A[T]`. Its algebra-homomorphism type is `B →ₐ[ℤ] A[T]`, not
`B →ₐ[A] A[T]`.

## Kernel and surjectivity of the normalization map

Mapping the principal ideal `(2)` along the constant map gives

`J = (ι_B(2))B = 2B`.

Here `2B` consists of constant-`2` multiples of elements of `B`; it is not the ideal
generated by `2t`. A polynomial `D(P)` vanishes exactly when every coefficient
`π(cₙ(P))` vanishes, equivalently when every normalized integer `cₙ(P)` is even.

If all these integers are even, write `cₙ(P) = 2dₙ`. The integers `dₙ` have finite
support, and the polynomial

`Q = ∑ₙ 2ⁿ dₙ tⁿ`

belongs to `B` by its coefficient condition. Coefficientwise, `P = 2Q`, hence `P ∈ 2B`.
Conversely, if `P = 2Q` with `Q ∈ B`, then `D(P) = D(ι_B(2)) D(Q) = 0`. This proves, for
this normalization map,

`ker D = 2B = J`.

The map `D` is surjective. Given `f = ∑ₙ bₙ Tⁿ ∈ A[T]`, choose an integer lift `cₙ` of
each of its finitely many nonzero coefficients and put `cₙ = 0` elsewhere. Then

`P = ∑ₙ 2ⁿ cₙ tⁿ ∈ B` and `D(P) = f`.

Only finite coefficient lifts along `ℤ → ℤ ⧸ (2)` are used, not a field structure on
`A`.

## Descent and identification of the canonical forward map

Since `ker D = J`, the normalization map descends to the original quotient:

`D̄ : C → A[T]`, with `D̄(q(P)) = D(P)`.

It is an injective ring homomorphism by the kernel computation and is surjective by the
coefficient lifts. To check its scalar compatibility, let `α : A → C` be the existing
algebra map. The original scalar tower gives, for every `m ∈ ℤ`,

`α(π(m)) = q(ι_B(m))`.

Consequently

`D̄(α(π(m))) = D(ι_B(m)) = κ(π(m))`.

Surjectivity of `π` implies `D̄ ∘ α = κ`. Thus `D̄` is an `A`-algebra homomorphism for
the existing structure on `C`; no new action or replacement quotient has been used.

Now set `η = q(2t)`. Its normalized coefficients consist of `1` in degree one and `0`
elsewhere, so

`D̄(η) = T`.

For the specified canonical map `F = Polynomial.aeval η`, the composite `D̄ ∘ F` fixes
every coefficient in `A` and sends `T` to `T`. It is therefore the identity on `A[T]`.

The other composite can also be checked on every representative of the original
quotient. If `P ∈ B` has normalized integers `cₙ`, its expansion in `B` gives

`q(P) = ∑ₙ α(π(cₙ)) ηⁿ = F(∑ₙ π(cₙ) Tⁿ) = F(D̄(q(P)))`.

Every element of `C` has such a representative. Hence `F ∘ D̄` is the identity on `C`.
The canonical evaluation map, not merely an unspecified bijection between the two rings,
is an `A`-algebra isomorphism with inverse `D̄`.

In particular, `η` satisfies no nonzero polynomial relation over `A`: if `f(η) = 0`,
applying `D̄` gives `f(T) = 0`, so all coefficients of `f` vanish. Since `A` is
nontrivial, this also gives `η ≠ 0`. This is a nontrivial example of a transcendental
degree-one generator in the original target quotient.

## Unit and trivial-ring boundaries

Let `R : Type u` be any commutative ring and let `a ∈ R` be a unit. For `I = (a)`, one
has `I = ⊤`, hence `A = R ⧸ I` is the zero ring. Also `J = I.map (algebraMap R B) = ⊤`,
so the original quotient `C` is the zero ring. The polynomial ring `A[T]` is the zero
ring as well. With `η = q(a t)`, the canonical `Polynomial.aeval η` is the unique map
between these one-element rings and is a bijection compatible with their `A`-algebra
structures.

Regularity here means that multiplication by `a` is injective, or equivalently that `ax
= 0` implies `x = 0`. A unit satisfies this condition by multiplication by its inverse.
This convention does not add `a ≠ 0` or a nontriviality assumption on `R`.

If `R` is the trivial ring, every ideal and every element is unique. In particular, `I =
⊥ = ⊤`, and the original `A`, `B`, `C`, and `A[T]` are all zero rings. The same
evaluation map is again the unique bijection. Multiplication by any `a` is injective on
a one-element set, and the cancellation condition `ax = 0 ⇒ x = 0` is tautological, even
for `a = 0`.

## Why nonzeroness is not enough

The complementary example `R = TrivSqZeroExt ℚ ℚ`, `a = ε`, `I = (ε)` is treated in [A
square-zero control for the symmetric algebra of the conormal
module](SymmetricAlgebraSquareZeroControl.md). There `ε ≠ 0` but `ε² = 0`, so
multiplication by `ε` is not injective. The section [Direct control of the original
target
quotient](SymmetricAlgebraSquareZeroControl.md#direct-control-of-the-original-target-quotient)
computes `J` as the constants from `I` and obtains `η = [εt] ≠ 0` with `η² = 0`. The
section [A nonzero square in the
source](SymmetricAlgebraSquareZeroControl.md#a-nonzero-square-in-the-source) supplies
the nonzero polynomial `X²` detector. In that example the nonzero polynomial `T² ∈ A[T]`
evaluates to zero at `η`, so the polynomial evaluation map is not injective. This is the
obstruction to replacing regularity by mere nonzeroness; no full symmetric-algebra
kernel description is asserted.
